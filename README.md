# 🥁 Drum Kit JavaScript

A fun and interactive **Drum Kit** built with **HTML, CSS, and JavaScript**. Play different drum sounds by clicking the buttons or pressing the corresponding keyboard keys.

### ✨ Features

* 🎵 Interactive drum sounds
* ⌨️ Keyboard controls
* 🖱️ Click-to-play buttons
* ⚡ Instant sound response
* 📱 Clean and responsive UI

### 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
